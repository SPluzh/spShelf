# План реализации: Окно редактирования кнопки полки с Live Preview (spShelf)

Данный документ описывает архитектуру, структуру интерфейса, параметры и пошаговый план внедрения полнофункционального окна редактирования кнопки полки с живым интерактивным предпросмотром (Live Preview) в `spShelf`.

---

## 1. Общие цели и требования

1. **Контекстное меню кнопки**:
   * Добавление пункта **«Edit Button...»** (с иконкой) в контекстное меню ПКМ для кнопок полки (`ShelfButton`).
   * Открытие специализированного окна редактирования параметров выбранной кнопки.
2. **Окно редактирования (`ButtonEditorDialog`)**:
   * Интуитивный интерфейс, полностью соответствующий стилистике тёмной темы Maya и системе масштабирования High-DPI (`self.scale`).
   * Организация параметров по тематическим вкладкам (Внешний вид и иконка, Команда, Пункты контекстного меню).
3. **Живой интерактивный предпросмотр (Live Preview)**:
   * Визуализация кнопки в реальном времени при изменении любого параметра (иконка, надпись, цвета, прозрачность, фон, ширина, наличие контекстного меню).
   * Использование реального рендерера `ShelfButton`, обеспечивающее 100% точность отображения (шрифты, сглаживание, контрастные обводки, треугольник выпадающего меню).
4. **Сохранение и отмена**:
   * Кнопка **«Save»** — валидация, сохранение структуры в `sp_shelf_data.json` и моментальное обновление интерфейса полки.
   * Кнопка **«Cancel»** — отмена без применения изменений.
   * Кнопка **«Reset»** — возврат к значениям на момент открытия диалога.

## 3. Редактируемые параметры кнопки

| Категория | Поле в JSON | Тип | Описание |
| :--- | :--- | :--- | :--- |
| **Иконка** | `image` / `image1` | `str` | Имя иконки Maya, путь к файлу или Qt-ресурс (`:/...`) |
| **Оверлейный текст** | `imageOverlayLabel` | `str` | Короткий текст поверх иконки (до 8-10 символов) |
| **Цвет текста** | `overlayLabelColor` / `labelColor` | `[r, g, b]` | RGB в диапазоне 0.0 – 1.0 |
| **Цвет подложки текста**| `overlayLabelBackColor` / `labelBackground` | `[r, g, b]` | RGB цвет фона плашки под текстом |
| **Прозрачность подложки**| `backgroundTransparency` | `float` | Альфа-канал подложки текста (0.0 — прозрачно, 1.0 — сплошной) |
| **Фон кнопки** | `enableBackground` | `bool` | Включение отображения пользовательского фона кнопки |
| **Цвет фона кнопки** | `buttonBackground` / `backgroundColor` | `[r, g, b]` | RGB цвет фоновой заливки самой кнопки |
| **Ширина кнопки** | `width` / `flexibleWidthValue` | `int` | Ширина кнопки в пикселях |
| **Режим ширины** | `flexibleWidthType` | `int` | `1`/`3` — стандартная ширина полки, `2` — фиксированная кастомная |
| **Имя кнопки** | `label` | `str` | Идентификатор / краткое имя кнопки |
| **Подсказка** | `annotation` | `str` | Всплывающий тултип при наведении курсора |
| **Язык команды** | `sourceType` | `str` | `"python"` или `"mel"` |
| **Основной скрипт** | `command` | `str` | Исполняемый код при клике ЛКМ |
| **Двойной клик** | `doubleClickCommand` | `str` | Исполняемый код при двойном клике ЛКМ (опционально) |
| **Пункты меню ПКМ** | `menuItems` | `list[dict]` | Список пунктов выпадающего меню (`label`, `command`, `sourceType`, `optionBoxCommand`) |

## 4. Механизм живого предпросмотра (Live Preview)

1. **Компонент предпросмотра**:
   * Создаётся экземпляр класса `ShelfButton` с параметрами редактируемой кнопки.
   * Кнопка размещается внутри контейнера предпросмотра с контрастным фоном полки Maya (`#383838`).
   * Клик по кнопке предпросмотра не запускает реальную команду, но корректно отображает визуальные состояния: обычное, hover (наведение мыши) и pressed (нажатие).
2. **Связывание сигналов (Reactive Updates)**:
   * Все контролы ввода формы связываются с обработчиком `_on_parameter_changed()`.
   * Изменение текста оверлея (`textChanged`) ➔ обновление `preview_button.overlay_label`.
   * Изменение цвета текста или подложки ➔ обновление `preview_button.label_color` / `preview_button.label_background`.
   * Изменение прозрачности ➔ пересчет `preview_button.background_transparency`.
   * Изменение иконки или выбор через диалог ➔ `preview_button._pixmap = get_maya_pixmap(new_icon)`.
   * Изменение ширины ➔ пересчет с учетом `scale` и вызов `preview_button.setFixedSize(...)`.
   * Добавление/удаление пунктов контекстного меню ➔ обновление структуры `preview_button.button_data["menuItems"]` (автоматически обновляет индикатор-треугольник выпадающего меню).
   * Вызов `preview_button.update()` для плавной перерисовки.

## 5. Вспомогательные компоненты UI

1. **`ColorPickerButton(QtWidgets.QPushButton)`**:
   * Компактная кнопка с цветным квадратом (превью текущего цвета) и hex/rgb меткой.
   * По клику открывает `QtWidgets.QColorDialog`.
   * Предоставляет методы `get_normalized_rgb()` (список `[r, g, b]` от 0.0 до 1.0) и `set_normalized_rgb(rgb_list)`.
2. **Вкладка пунктов меню (`PopupMenuEditorTab`)**:
   * Список (`QListWidget` / `QTreeWidget`) существующих команд меню кнопки.
   * Кнопки управления:
     * `[ + Add Item ]` — добавление нового пункта.
     * `[ - Delete Item ]` — удаление выбранного пункта.
     * `[ ▲ Up ]` / `[ ▼ Down ]` — изменение порядка следования пунктов.
   * Редактор выбранного пункта:
     * Название (Label).
     * Язык (Python / MEL).
     * Команда (Command).
     * Опциональная команда Option Box (`optionBoxCommand`) для открытия окна настроек.

## 6. Интеграция с ядром полки (`spShelf.py`)

1. **Контекстное меню `ShelfButton._show_context_menu`**:
   * Добавление действия:
     ```python
     edit_action = menu.addAction(get_maya_icon("edit.png"), "Edit Button...")
     edit_action.triggered.connect(lambda: self.shelf_manager.open_button_editor(self.shelf_index, self.button_index))
     ```
2. **Метод в `ShelfManager.open_button_editor(shelf_idx, button_idx)`**:
   * Проверка граничных условий и валидности индексов.
   * Создание и отображение экземпляра `ButtonEditorDialog`.
3. **Сохранение и обновление**:
   * Запись обновленных данных в `self.shelves[shelf_idx]["buttons"][button_idx]`.
   * Вызов `self.save_user_data()` для сброса на диск в `sp_shelf_data.json`.
   * Вызов `self.window_widget.rebuild_content()` для мгновенной перерисовки полки с новым видом кнопки.
